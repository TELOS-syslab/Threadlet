
## Overview

This artifact provides the source code and experiment entry points for the
following evaluation figures:

- **Figure 7:** context-switch, scheduling, thread-to-thread notification, and
  device-to-thread notification latency;
- **Figure 8:** scheduling overhead and throughput;
- **Figure 10:** networking performance with different kinds of requests;
- **Figure 13:** lock throughput and handoff latency, comparing LoomOS with
  Linux Mutex, Argobots, and mcs-b (blocking MCS).

## Environment setup

The offline RISC-V toolchain archive uses Git LFS. Install Git LFS and run
`git lfs pull` from the repository root before building the baselines.

Threadlet builds upon Rocket-chip, and has been test on Xilinx VCU118 FPGA board using the Chipyard development environment and evaluated it using cycle-accurate AWS FPGA-accelerated simulations with Firesim. Follow [chipyard-setup](https://chipyard.readthedocs.io/en/stable/Chipyard-Basics/Initial-Repo-Setup.html#setting-up-the-chipyard-repo) and [firesim/VCU118-setup](https://docs.fires.im/en/latest/Getting-Started-Guides/On-Premises-FPGA-Getting-Started/Xilinx-VCU118-FPGAs.html) to setup the environment for both chipyard, firesim and VCU118 on ```./chipyard```.

LoomOS builds upon Asterinas, which is a _secure_, _fast_, and _general-purpose_ OS kernel
that provides _Linux-compatible_ ABI. It can serve as a seamless replacement for Linux
while enhancing _memory safety_ and _developer friendliness_.

**Tested Versions:**
* **Chipyard:** `1.13.0`
* **FireSim:** `1.20.1`
* **Asterinas:** `0.11.1`



The hardware implementation is under
`chipyard/generators/rocket-chip`, while the FPGA experiment launchers and
hardware-log analyzers are under `loomOS/eval`.



## Build LoomOS

Start the LoomOS build container from the artifact directory:

```bash
cd Threadlet-AE/loomOS
./docker_start_debug.sh
```

Inside the container, build the RISC-V LoomOS kernel and all experiment device
trees:

```bash
cd /root/asterinas
./build-os.sh
```

The build command produces the optimized RISC-V kernel used by the FPGA
experiments and compiles the device-tree source files under `loomOS/tools` into
DTB files.

## Running the Experiments

Run the figure scripts one at a time from the artifact script directory. The
recommended order is important because the Figure 7 analysis consumes logs
generated by the other experiments.

```bash
cd Threadlet-AE/script
./figure8.sh
./figure10.sh
./figure13.sh
./figure7.sh
```

Figure 7 need to uses the hardware logs produced by Figures 8, 10, and 13, so
`figure7.sh` must run after all three experiments have completed.

Each script runs its LoomOS experiment, parses the hardware log into a CSV file,
and generates the corresponding PNG in `Threadlet-AE/result`.
